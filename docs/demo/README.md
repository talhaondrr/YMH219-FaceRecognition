# Demo fotoğrafları ve kaynaklar

- `astronaut.jpg`: Eileen Collins, NASA. scikit-image örnek veri kümesi; kamu malı / bilinen telif kısıtlaması yok. [Kaynak ve kullanım açıklaması](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut), [indirilen dosya](https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/data/astronaut.png).
- `grace_hopper.jpg`: Grace Hopper, James S. Davis / U.S. Navy. Matplotlib örnek verisi. [Fotoğraf ve kamu malı bildirimi](https://commons.wikimedia.org/wiki/File:Grace_Hopper.jpg), [indirilen dosya](https://github.com/matplotlib/matplotlib/blob/main/lib/matplotlib/mpl-data/sample_data/grace_hopper.jpg).

Fotoğraflar internetten alınmış kamuya açık demo verileridir; gönüllü yerel veri toplandığı iddia edilmez. Föydeki yerel/gönüllü örnek koşulu ayrıca yerine getirilmelidir.

## Ekranları yeniden oluşturma
1. Uygulamayı açın, Görüntü seç ile `astronaut.jpg` dosyasını seçin.
2. `Ornek_A` etiketiyle Örneği etikete ekle düğmesine basın.
3. `grace_hopper.jpg` dosyasını seçip `Ornek_B` etiketiyle ekleyin.
4. İki dosyayı sırayla açın. Yüz çerçevesi, etiket ve LBPH uzaklığı görünür.

Ekran görüntüleri eğitimde kullanılan aynı fotoğrafları gösterir; bağımsız test doğruluğu ölçülmemiştir. Bu yüzden uzaklık 0 olabilir; bu, yüzde 100 doğruluk anlamına gelmez. Eğitim bellektedir, uygulama kapandığında silinir.
